# Sentiment Analysis Using Multinomial Naive Bayes

A simple sentiment-classification project implemented from scratch.

## Algorithm
Multinomial Naive Bayes

## Classes
- 1 = Positive
- 0 = Negative

## Pipeline
Text -> Tokenization -> Word Frequencies -> Naive Bayes -> Probability -> Sentiment

## Files
- dataset.py: training sentences
- preprocess.py: text tokenization
- naive_bayes.py: Naive Bayes algorithm
- main.py: training and predictions
- visualize.py: confusion matrix result

## Install
pip install matplotlib

## Run
python main.py
python visualize.py
